ADS 352 Dersi İçin Örnek Kişisel Web Sitesi

Hakkımda

Merhaba, ben ARDA Samed Kütük. Bu web sitesi, ADS 352 dersi kapsamında örnek bir kişisel web sayfası oluşturma amacıyla hazırlanmıştır.

Bu proje ile HTML ve CSS kullanarak temel web tasarımı, sayfa düzeni oluşturma ve kullanıcı dostu arayüz geliştirme konularında pratik yapılmıştır.

Proje Amacı

Bu sayfanın amacı; tek sayfa (single-page) web sitesi yapısını öğrenmek, CSS'in HTML içine gömülü kullanımını görmek ve basit animasyonlar ile sayfayı daha modern hale getirmektir.

Ayrıca responsive (mobil uyumlu) tasarım ve kullanıcı deneyimi konularına giriş yapılmıştır.
